Как подключить в NextGIS QGIS подложку ЕЭКО
===========================================

.. important:: Компания NextGIS не имеет отношения к упоминаемым здесь сторонним сервисам, по вопросам их функционирования необходимо связываться с их техподдержкой.

1. Убедиться, что ваш компьютер находится в РФ. Для этого, открыть ``https://yandex.ru/internet/`` и убедиться что адрес в РФ.

2. Установить `NextGIS QGIS <https://nextgis.ru/nextgis-qgis/>`_.

3. Установить сертификаты Минцифры

Скачать и установить по инструкции три сертификата ``https://www.gosuslugi.ru/landing/crt``

4. Добавить сертификаты в NextGIS QGIS

* Открыть NextGIS QGIS.
* Меню: :menuselection:`Настройки --> Параметры --> Аутентификация --> Управление сертификатами --> Полномочия (вкладка)`.
* Нажать зелёную кнопку "+", выбрать файл сертификата. Это нужно повторить для каждого из трёх сертификатов.
* После добавление сертификатов - перезапустить QGIS.

Теперь можно подключать TMS сервисы ЕЭКО используя одну из двух ссылок::

   https://nspd.gov.ru/cgk/map/38/tms/{z}/{x}/{y}.png
   https://ngw.fppd.cgkipd.ru/tile/56/{z}/{x}/{y}.png

Для подключения ознакомьтесь с инструкцией `Подключение TMS <https://docs.nextgis.ru/docs_ngqgis/source/map.html#ngqgis-map-tms>`_.

После подключения - приблизьтесь к нужной территории, чтобы подложка начала отображаться.
